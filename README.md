# HitamaruPlugins
This is Hitamaru16's custom plugin repository for Dalamud.

## How to Use
* Open Dalamud Settings (`/xlsettings`).
* Go to the `Experimental` Tab.
* Under "Custom Plugin Repositories", add the following URL:
`https://raw.githubusercontent.com/Hitamaru16/HitamaruPlugins/main/plugins.json`
* Click the `+` Button and save.

If done correctly, you can find Hitamaru16's Plugins in the Plugin Installer (`/xlplugins`)
